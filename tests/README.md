# Verification

`pnpm test` runs Vitest domain, FHIR, PostgreSQL integration, security and workflow tests. Database suites create and remove random temporary schemas in the local synthetic PostgreSQL database. `TEST_DATABASE_URL` can select another local database. Integration authentication injects a test-only verified-identity provider into `buildApp`; the real identity mapper, onboarding gates and record authorization still run. No test authentication endpoint or environment bypass exists in the application.

`pnpm test:e2e` runs the Playwright lifecycle, accessibility and interrupted-response checks against the prototype at `http://localhost:3001` (`PLAYWRIGHT_BASE_URL` can override this). It uses real Clerk sessions through `@clerk/testing/playwright`, following [Clerk’s Playwright guidance](https://clerk.com/docs/guides/development/testing/playwright/overview). Provide development `CLERK_PUBLISHABLE_KEY` and `CLERK_SECRET_KEY` securely to the test process; production keys are rejected.

For authenticated browser scenarios, set `CLERK_E2E_CLINICIAN_EMAIL`, `CLERK_E2E_PATIENT_EMAIL`, `CLERK_E2E_ADMIN_EMAIL`, `CLERK_E2E_COORDINATOR_EMAIL` and `CLERK_E2E_RECEIVER_EMAIL` for the roles exercised. Each must identify an existing verified Clerk development user explicitly linked by a trusted operator to the corresponding fixed synthetic local ID (`user-clinician`, `user-patient`, and so on). The test helper asserts that mapping before clinical steps. It never creates users, grants privileges, links by email, or accepts legacy demo passwords. Missing role fixtures fail with a setup explanation; individual specs can run with only their required identities.

Use a dedicated synthetic database for browser scenarios because they intentionally create and update care episodes. Python pytest covers the separate research component. See [recorded results](../docs/evaluation/results.md) and [limitations](../docs/evaluation/limitations.md); historical browser results are not evidence that the Clerk migration has passed live browser verification.
